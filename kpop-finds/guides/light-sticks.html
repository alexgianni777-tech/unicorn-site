K-pop light sticks: what to check before you buy

A fanlight can be one of the best fandom gifts — and one of the easiest products to buy in the wrong version.

Check these five things

  1. Official status. Start with the artist's official store or label source.
  2. Version. Some groups release multiple generations with different features.
  3. Concert compatibility. Venue syncing or app features can depend on the current model.
  4. What is included. Batteries, straps, stands and cases vary.
  5. Seller and returns. Marketplace counterfeits exist, so seller identity matters.
